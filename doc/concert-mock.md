# 콘서트 관람 기록 Mock API

백엔드의 `/api/v1/concert-records` 8개 API가 구현되기 전 화면 개발에 사용하는 MSW 응답입니다. 공연과 포스터는 Figma 시안용 가상 데이터이며 KOPIS에서 받은 실제 정보가 아닙니다.

- `npm run dev`: 콘서트 Mock이 기본 활성화됩니다. 다른 API 요청은 기존 서버로 통과합니다.
- `VITE_ENABLE_CONCERT_MOCKS=false`: 로컬 개발에서 Mock을 끕니다.
- `VITE_ENABLE_CONCERT_MOCKS=true`: 배포 미리보기 빌드에서도 Mock을 켤 수 있습니다.
- 요청에는 기존 로그인 토큰이 필요합니다. 토큰별로 분리한 기록을 브라우저 `localStorage`에 저장합니다. 초기 화면에는 관람 예정 1건, 관람 완료 1건이 들어 있습니다.
- 초기 데이터로 되돌리려면 브라우저 저장소에서 `discpedia:concert-mock:v1:`으로 시작하는 키를 삭제하고 새로고침합니다.

목록·상세·등록·수정·삭제, 후기 저장·삭제, 셋리스트 전체 교체를 지원합니다. 동일 공연명·날짜·공연장·회차의 중복 등록은 `409`로 응답합니다. 실제 서버 구현 전에는 이 Mock의 세부 오류 응답과 데이터 형식을 백엔드 계약에 맞춰 다시 확인해야 합니다.
